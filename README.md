# SF AOC Meteo

顺丰航空 AOC 机场气象查询与预报工具集。输入机场四字码，可查看机场精细化天气预报、多维度中长期预报，以及全球机场日出日落时间。

在线访问：

- 精细化机场天气预测：[index.html](https://xzyl11169.github.io/sfa_meteo/)
- 多维度机场预报：[index2.html](https://xzyl11169.github.io/sfa_meteo/index2)
- 全球机场日出日落查询：[index3.html](https://xzyl11169.github.io/sfa_meteo/index3)

## 功能概览

### `index.html` 精细化机场天气预测

- 输入机场四字码查询未来 7 天逐小时精细化天气预报。
- 展示温度、露点、降水、风、云量、湿度、气压等关键气象要素。
- 使用图表方式展示时序变化，便于值班和运行参考。

### `index2.html` 多维度机场预报

- 支持精细化预测、集合预报、延伸期预报、季节预报和气候预估。
- 面向机场中短期和中长期天气趋势查看。
- 适合对同一机场进行多时间尺度天气研判。

### `index3.html` 全球机场日出日落查询

- 输入机场四字码和年份，生成全年日出日落时间表。
- 支持 UTC 和 LT 两种显示模式。
- 自动定位并高亮机场当地日期的今天。
- 数据库加载支持耗时显示、超时控制和本地缓存兜底。
- 页面内置算法说明和更新说明，可展开查看。

## 数据来源

本项目主要使用以下公开数据或服务：

- [Open-Meteo](https://open-meteo.com/)：天气预报、集合预报、季节预报、气候预估等。
- [mwgg/Airports](https://github.com/mwgg/Airports)：全球机场基础数据。
- [SunCalc](https://github.com/mourner/suncalc)：日出日落时间计算。
- [Apache ECharts](https://echarts.apache.org/)：图表渲染。

第三方数据源可能存在接口调整、访问限制或临时不可用的情况。若页面无法加载数据，请先检查网络、浏览器控制台和第三方接口状态。

## 使用方式

本项目为纯静态页面，可直接通过 GitHub Pages 访问，也可以下载后本地打开 HTML 文件。

本地运行建议使用简单 HTTP 服务：

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000/
```

## 日出日落算法说明

`index3.html` 的日出日落时间基于机场经纬度、机场所在时区和可用机场标高进行理论计算。

注意：

- 日期按机场所在时区解释，避免跨时区机场日期偏差。
- 若机场数据库提供标高字段，会进行近似高度修正。
- 未校正周边山体、建筑物遮挡和实时大气折射。
- 结果适合作为值班参考和日照时间表，不作为精密天文或运行标准依据。

## 维护说明

- 页面为前端静态工具，主要逻辑均在对应 HTML 文件内。
- 更新页面后，推送到 `main` 分支即可触发 GitHub Pages 刷新。
- GitHub Pages 更新可能需要几十秒到几分钟。
- 如页面未立即变化，可使用强制刷新，或在 URL 后增加查询参数，例如 `?v=20260604`。
